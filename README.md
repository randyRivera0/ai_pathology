# AI Pathology

Research and educational repository for independent artificial-intelligence
experiments in computational pathology. Individual experiments may use
different datasets, models, protocols, and runtime environments.

> This project is not a medical device and must not be used for diagnosis or
> clinical decision-making. Model confidence is not a calibrated clinical
> probability.

## Repository structure

- `frontend/`: NiceGUI prototype application.
- `backend/`: inference orchestration and independently managed models.
- `docs/`: project documentation and preserved milestone information.
- `experiments/`: independent experiment records and evaluation evidence.
